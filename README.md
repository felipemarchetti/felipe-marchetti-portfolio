# Felipe Marchetti Portfolio

Portfolio profissional de Felipe Cunha Marchetti, desenvolvedor full-stack com foco em e-commerce, PHP, Laravel, JavaScript, SQL e analise de dados.

A versao publicada pelo GitHub Pages fica em:

https://felipemarchetti.github.io/felipe-marchetti-portfolio/

## Conteudo

- `github-pages/index.html`: versao estatica publicada no GitHub Pages.
- `github-pages/assets/`: assets visuais do portfolio.
- `github-pages/cv/`: curriculo em PT e resume em EN.
- `.github/workflows/github-pages.yml`: deploy automatico do GitHub Pages.
